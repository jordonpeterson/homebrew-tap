# homebrew-tap

Homebrew formulae for [@jordonpeterson](https://github.com/jordonpeterson)'s tools.

## Usage

```sh
brew install jordonpeterson/tap/codeowners-tool
```

or

```sh
brew tap jordonpeterson/tap
brew install codeowners-tool
```

## Formulae

- **codeowners-tool** — safe, intent-level, verifiable CODEOWNERS changes.
  Source: [jordonpeterson/codeowners-tool](https://github.com/jordonpeterson/codeowners-tool)
